# 📊 Featured Project

# Superstore Retail Analytics Dashboard (Power BI)

## 📌 Project Overview

The **Superstore Retail Analytics Dashboard** is an interactive **Business Intelligence solution** developed using **Microsoft Power BI** to analyze retail sales data.

The dashboard provides insights into:

* Sales performance
* Profit trends
* Regional sales distribution
* Product category performance
* Customer segmentation

Through visual analytics and KPI tracking, this dashboard helps organizations **understand business performance and support data-driven decision making.**

---

## 🛠 Tools & Technologies

* Microsoft Power BI
* Data Visualization
* DAX (Data Analysis Expressions)
* Data Modeling
* Business Intelligence Techniques

---

## 📂 Dataset

The dataset used in this project contains retail transaction records including:

* Order ID
* Customer Segment
* Region
* Product Category
* Sales
* Profit
* Order Date
* Quantity

This dataset allows comprehensive analysis of **sales trends, profitability, and regional performance.**
